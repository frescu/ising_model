# Ising model in Python

This is a personal project to implement the 2D Ising model. There will be a main.py program which will import different packages that
follow all the steps necessary to run the simulation: Creating the lattice, running the Metropolis algorithm, obtaining the different
observables that describe the system, creating graphs that help to find the characteristic temperature and analyse the behaviour, etc.

My goal with this work is to become more familiar with the processes required to represent a physical system and the laws that govern
it on a computer. Hence, learning some useful tools such as Git/GitHub or scientific Python, is critical. Furthermore, this project is 
an opportunity to observe the physics learnt in college from a different perspective , a more tangible one.

## Goals

- Implementing the 2D ising model
- Study the phase transition
- Learn scientific Python
- Practise Git
- Apply Machine Learning (yet to implement)
